# Evaluation protocols

The protocol documents define how the three experiment families are executed
and interpreted. They are intentionally separate from results: changing an
analysis description must not rewrite retained measurements.

- [`policy-and-recovery.md`](policy-and-recovery.md)
- [`template-extraction.md`](template-extraction.md)
- [`versioned-datasets.md`](versioned-datasets.md)

The machine-readable registrations are in `experiments/catalog.json`.
