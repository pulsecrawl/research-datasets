# Methods and environment

This folder contains the written procedures and software pins used by the
experiments. It does not contain results.

- [`protocols/`](protocols/) explains what each experiment family measures and
  how a result is interpreted.
- [`environment/`](environment/) records the compatible PulseCrawl version and
  the Python dependencies used to reproduce the public runs.
- [`images/`](images/) contains previews of generated fixtures only. No image
  was captured from a live third-party website.
