# Weather and environmental alerts live study

This category contains 7 websites selected for the two-cycle
qualification. A later 24-hour study is
configured separately and is not started by the qualification command.

| Website | Stable ID | Qualification URL |
|---|---|---|
| UK Met Office Warnings | `weather-uk-met-office` | https://weather.metoffice.gov.uk/warnings-and-advice/uk-warnings |
| Met Éireann Warnings | `weather-met-eireann` | https://www.met.ie/warnings-today.html |
| KNMI Netherlands Warnings | `weather-knmi-nl` | https://www.knmi.nl/nederland-nu/weer/waarschuwingen/utrecht |
| AEMET Spain Warnings | `weather-aemet-es` | https://www.aemet.es/en/eltiempo/prediccion/avisos |
| Météo-France Vigilance | `weather-meteofrance` | https://vigilance.meteofrance.fr/fr |
| Finnish Meteorological Institute Warnings | `weather-fmi-finland` | https://en.ilmatieteenlaitos.fi/warnings |
| Meteorological Service Singapore Heavy Rain Warning | `weather-mss-singapore` | https://www.weather.gov.sg/warning-heavy-rain/ |

Exact hosts, discovery limits, and template mappings are in
[`input/sites.json`](input/sites.json). Completed evidence appears under
`runs/`; an empty `runs/` folder means that no public run has been released.
