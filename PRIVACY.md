# Publication boundary

This repository starts with fresh Git history and account-only commit attribution.

Included files are selected synthetic inputs, generators, expected values, generic configuration, and checksums. Original commit history, thesis PDFs, author metadata, workstation paths, environment files, live request logs, credentials, and raw research result directories are excluded.

Pre-publication checks examine staged file contents, filenames, and Git author/committer metadata for personal identifiers, absolute home paths, non-project email addresses, credential patterns, and private service URLs. Binary or unreviewed files are not included.

Checks reduce disclosure risk; they are not a guarantee against all possible indirect identification. The repository owner account and ordinary GitHub platform metadata remain public. Keep future contributions within this boundary.
