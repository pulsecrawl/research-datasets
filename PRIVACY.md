# Publication boundary

This repository starts with fresh Git history and account-only commit attribution.

Included files may contain selected synthetic inputs, generators, expected
values, registered experiment configurations, sanitized execution manifests,
bounded measurements, derived analysis, and checksums. Original private commit
history, manuscripts, author metadata, workstation paths, machine identifiers,
credentials, downloaded third-party HTML, sensitive headers, unreviewed live
request logs, and raw workspace directories are excluded.

Pre-publication checks examine staged file contents, filenames, and Git
author/committer metadata for personal identifiers, absolute home paths,
non-project email addresses, credential patterns, and private service URLs.
The only reviewed binary files are PNG renders of generated synthetic fixtures.
They are checksum-covered, checked for embedded metadata, and contain no
external website pixels. Other binary or unreviewed files are not included.
Public environment records contain only the package version, Python version,
and generic operating-system and architecture information; they must not
contain usernames, hostnames, or absolute paths.

Checks reduce disclosure risk; they are not a guarantee against all possible indirect identification. The repository owner account and ordinary GitHub platform metadata remain public. Keep future contributions within this boundary.
