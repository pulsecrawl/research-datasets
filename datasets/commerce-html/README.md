# Fictional commerce observations

This collection contains 20 generated documents representing two observations
of ten fictional stores. Each store keeps the same fictional product identity
while the controlled price changes from USD 120 to USD 99.

The values are test inputs, not observed market prices. Hosts end in `.example`,
product names begin with `SYNTHETIC`, and `manifest.jsonl` records the expected
structured fields and checksum for every document.

The HTML is primarily JSON-LD and metadata, so several files appear blank when
opened visually. They are designed for structured extraction rather than as
realistic storefront pages. No external commerce page or screenshot is stored
in this collection.
